# Code of Conduct

This project follows a simple standard: be direct, useful, and respectful.

## Expected Behavior

- Focus on the technical issue.
- Give reproducible steps, logs, and versions when reporting bugs.
- Treat security reports and user data carefully.
- Disagree with code or decisions without attacking people.

## Unacceptable Behavior

- Harassment, abuse, or discriminatory language.
- Publishing secrets, credentials, private logs, or personal data.
- Spam, off-topic promotion, or intentionally disruptive behavior.

## Enforcement

Maintainers may edit, hide, or remove issues, comments, or pull requests that violate this standard.
